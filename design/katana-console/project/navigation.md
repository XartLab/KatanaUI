# 侧栏导航与滚动条

> 2026-11-17 定（用户在文档站上逐条确认）。实现：`@katana-ui/react` 的 `SideNav`（`packages/react/src/patterns/side-nav.tsx`、`src/theme/side-nav.css`）；文档站目录是它的第一个使用方。KATANAview 的侧栏、设置页目录、文档目录都用它，不另写。

## 1. 来源

照 rareui.com 组件站的左栏（2026-11-17 在用户 Chrome 里实测结构与数值），实现原创。用户原话：「为什么我们的没法跟 Rare UI 左侧栏一样」「滑条要小，再加上要有图标 logo 等东西」「大分组有，小分组没 logo」。

## 2. 结构

自上而下：

| 区 | 内容 | 规格 |
|---|---|---|
| 头 | 收起按钮 · logo · 面包屑 | 收起按钮 32×32、圆角 8、`alpha-white-6` 底；logo 20×20；面包屑 15/20，上级 55% 亮度，当前级 `ink-100` 500 |
| 过滤框 | 搜索组件与页面 | 高 30、圆角 8、`alpha-white-2` 底、`alpha-white-8` 边；右侧 `⌘K` 键帽；⌘K / Ctrl+K 聚焦，Enter 打开第一项，Esc 清空；没命中的组整组隐藏 |
| 分组 × n | 组名 + 链接列 | 组与组间距 20 |
| 尾（可选） | 版本、链接 | — |

- 栏宽 300（文档站）；贴着页面底色，**不加边框**；右边的内容区是一块圆角 16 的面板（`bg-100`、1px `line-100` 内描边、离屏边 8）。
- 栏底 48px 淡出（mask），提示还能往下滚。
- 收起后栏消失，展开按钮挪到内容区顶栏最左。

## 3. 分组与条目

- **组名**：11/16、600、大写、字距 0.14em、`ink-100` 的 40%。**大分组带图标**：14px lucide 图标，`ink-100` 的 65%，在组名前，间距 6。
- **条目不带图标**（小分组没 logo）。`SideNav` 支持条目图标，只是我们不用。
- **条目**：14/20、400，内距 6 / 8 / 6 / 20（左边 20 留给轨迹），圆角 8，条目间距 2；单行，放不下用省略号。
  - 未选中 `ink-100` 的 50%；悬停 80%；当前项 100%。颜色过渡 200ms。
  - 组件条目写「英文名 + 中文名」，中文名小一号（0.86em）、70% 亮度，括号里的补充说明不进目录。
- 文字档跟渲染设置走：字重加 `--k-weight-adjust`，字号乘 `--k-text-scale` 后取整（rendering.md）。

## 4. 轨迹（签名元素）

- 每组左侧 2px 处一条 **1px 虚线**（2px 实 2px 空，`repeating-linear-gradient`），从组顶画到**当前项中线上方 6px**，再接一个 **6px 半径的弯钩**（12×7 的 SVG，`M0.5 0a6 6 0 0 0 6 6H12`，同样 2/2 虚线）拐进当前项。
- 当前项轨迹用 `--k-sidenav-trail`，默认 `--accent`（品牌橙）。这是导航指引，不是选中态控件；要中性就把变量设成 `ink-200`（#55 定过「操作件选中态用中性高亮」，轨迹是否跟它走待用户最后定）。
- 悬停另一项时，另画一条 `ink-100` 30% 的淡色轨迹到悬停项；离开组时淡出。
- 换当前项时轨迹 `top` / `height` 走 200ms 过渡（滑过去）；`prefers-reduced-motion` 时不过渡。
- 轨迹位置量布局得出（`offsetTop`），直接写 style、不进 React 状态；`ResizeObserver` 跟着重算。
- 打开某页时，当前项不在视口就滚过去，并让它所在的组名一起露出来。

## 5. 滚动条

用户原话：「滑条要小」。

- **全站细滚动条**：`scrollbar-width: thin`，滑块 `alpha-white-13`，轨道透明（`theme/rendering.css` 的 `:root`，往下继承，所有可滚区域都生效）。macOS 叠加滚动条不受影响。
- **侧栏**：滚动条平时透明，鼠标进栏才显出来。
- 不做自绘滚动条；表格等虚拟滚动区域用同一套颜色。

## 6. 不做

- 不做多级展开树（两级够：大分组 → 条目）。
- 不给条目加图标、徽标或计数。
- 轨迹不加发光、不加动画循环。
