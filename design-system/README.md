KATANA Console 的组件库：给量化与交易界面用的深色控制台风格组件，Radix 做行为底座，Tailwind v4 写样式，颜色、字体、间距、动效全部取自 token。涨跌色可以互换（红涨绿跌），行情的格式化由调用方传参。

## 内容基本法

- 界面文字以中文为主，由调用方传进来；包里的件不写死任何文案，包里不出现中文（演示与预览除外）。
- 不画假数据：没有连接就显示空态，不放样本 K 线、样本盘口、演示品种。预览与展示页里的数值都是示例，要标明是示例。
- 未知的值写 `— —`（`ink-300`），不写 0。估算出来的值必须带「估算」角标。
- 品种写成「代码.场所」，场所用 ISO MIC（`600519.XSHG`）；件只收 `{ code, venue }` 这样最小的普通类型，不收应用里的品种对象。
- 价格、数量、盈亏的小数位、最小变动价位、千分位、单位由调用方传；件里不猜。数字列用等宽数字对齐。
- 涨跌与盈亏除了颜色，必须还有符号或箭头：颜色可能被换成红涨绿跌，色盲也分不出。件只读 `pnl-up`、`pnl-down`，不写死绿或红。
- 错误文案先写怎么办、再写为什么，每句不超过 12 个字，不用感叹号，不道歉；带上任务 id 与时间。
- 状态（空、加载、错误、断线、过期）只占内容区，表头与外框保留；说清发生了什么、影响什么、能做什么。

## 视觉基础

- 颜色只取 token：写 `var(--bg-300)` 或 Tailwind 主题类，不写色值。底从暗到亮五层：`bg-000` 凹陷（输入框、LCD 窗），`bg-100` 地面，`bg-200` 单元格，`bg-300` 面板主体，`bg-400` 悬停与浮起层。
- 文字分层：`ink-100` 只给数据（数值、当前对象），正文用 `ink-200`，说明、时间戳、单位用 `ink-300`。`ink-400` 不是文字，只给刻度与占位。`ink-300` 在 `bg-400` 上不到 4.5:1，不要在悬停底上放小字说明。
- 对比度已在 `tokens.json` 的 `contrast` 里按两个主题量过：`ink-100`、`ink-200`、各 `signal-*`、`pnl-up`、`pnl-down` 在五层底上够 4.5:1，`focus-ring` 够 3:1。没过线的写在该 token 的用法里，保留原值，不另改色。
- 强调色 `signal-orange` 只给「活的」东西：焦点、选中、LED。发光体每屏不超过 3 个；同一时刻运动的元素不超过 1 个。
- 涨跌色：`pnl-up`、`pnl-down` 默认绿涨红跌；根元素加 `data-updown="cn"` 互换成红涨绿跌，件不用改。表示错误与危险的 `signal-red` 不跟着换。
- 主题：Console 在 `:root`，Graphite 用 `data-theme="graphite"` 覆盖；只改颜色、圆角、玻璃与阴影，字号不变。
- 字体：界面文字六档（`display`、`title`、`body`、`data`、`caption`、`micro`），签名件三档（`lcd`、`tag`、`tag-md`）；件里写 `k-text-data` 这样的档名，不写数字字号。`lcd` 与 `tag` 只放短的数字与大写拉丁。
- 间距：4px 基准，padding、margin、gap 只取 `space-*` 的刻度。数值列之间至少 12px，列间距至少 8px。分组靠间距，不靠边框。
- 圆角：面板是方的（`radius-panel` 0），控件 `radius-control`，浮层 `radius-overlay`，内层 `radius-inner`；Graphite 下各档不同，用变量不用数字。
- 阴影表达材质，不表达高度：`plate`（金属板）、`recess`（凹陷）、`glow-orange`（发光体）、`lift`（浮起）。它们在 `components/bundle.css` 里随 token 带着。
- 状态：悬停提亮一档；按下缩到 0.97；键盘焦点画 `focus-ring` 的外框（贴边的小按钮画在里面）；禁用 45% 不透明度并且不响应指针。
- 动效用三条弹簧（`--ease-snappy`、`--ease-gentle`、`--ease-settle`，时长 `--dur-*`），入场、退场写在 `theme/motion.css`。动效只给用户自己的动作，不给市场结果：价格、盈亏、成交没有重量感。不做「减少动态效果」选项。
- 浮层件（Tooltip、Popover、Dialog、菜单）在静态预览里服务端不渲染，预览摆触发器；它们打开后的样子在展示页里看。

## 图标

- 图标用 `lucide-react`，线性、不填充，颜色永远 `currentColor`，由文字 token 决定。按钮里的图标 13px，图标按钮里 15px。
- 只用用得着的几个：设置、关闭、加号、下拉箭头、播放暂停、锁、眼睛（遮蔽金额）、警示三角、勾。不用表情类、填充类、品牌类。
- 图标按钮 28px，必有 `aria-label`。图标不单独承载状态，旁边必有文字或 LED。
- 交易场所的标记（`VenueLogo`）与资产图标由应用提供，设计系统包不带 `assets/logos/`；没有对应图标时显示场所代码，不画假标。
- 控制台专用图标（LED、阶梯、盘口带等）画在 `design/katana-console/project/` 的设计稿存档里，那里是存档，不是组件库的权威。
