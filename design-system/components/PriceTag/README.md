# PriceTag

夹在一句话或一行里的「名字 价格 涨跌」，数字等宽对齐，涨跌带三角与颜色，跟着周围的字号走。

## Provide

### PriceTag

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `name` | `string` | — | 品种名或代码；不给就只有价与涨跌。 |
| `price` | `string` | — | 已格式化好的价。 |
| `change` | `string` | — | 已格式化好的涨跌（带符号）。 |
| `tone` | `'up' \| 'down' \| 'flat'` | `'flat'` | 涨跌三态：定颜色与三角（▲ ▼，平没有）。 |
| `label` | `string` | — | 读屏读的整句；不给就读可见的字。 |

## States

- 涨、跌：涨跌文字带三角与对应颜色。
- 平：没有三角，用弱色。
- 只有价格：不写名字与涨跌。

## Don't

- 不要只靠颜色表达涨跌：三角与带符号的文字必须在。
- 不要在包里格式化数字，价与涨跌由调用方传好。

## Composition

```
PriceTag
  span（名字）
  span（价）
  span（三角 · 涨跌）
```
