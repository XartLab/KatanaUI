文字平滑

灰度：每个像素只算明暗，字边在暗底上更干净。系统：交给操作系统（macOS 可能是子像素）。Windows 的 ClearType 由系统管，在「调整 ClearType 文本」里调。

像素对齐

网格、基线、柱子与格子的边吸到屏幕像素上，1px 线不会糊成两条浅线。曲线不吸。

字重补偿

暗底上的浅色字看着比实际粗，不同显示器与平滑方式也不一样；往负调变细，往正调变粗。只改笔画粗细的观感，不改字号。

0
字号

全部文字一起缩放，结果取整到整像素，行高跟着走。

100%
斜线零

数字 0 带斜线，跟字母 O 区分（代码、订单号、价格）。

中英对齐

按大写字母高度把汉字字体缩放到跟英文一致，混排时大小更齐；汉字可能略大或略小，按观感开关。
