# WaterfallChart

期初权益到期末权益的桥：起点一根总计柱，中间每一步是一根浮动的增减柱（涨跌色跟涨跌配色走），末尾一根总计柱，相邻柱之间连水平线。指针或 ←→ 扫读。功能参照 Arc 的 MRR waterfall。

## Provide

### WaterfallChart

总计柱与前面累计起来的不相等时，柱照它自己的值画、画虚线框，差额在读数里给出：不替调用方把桥抹平。

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `steps` | `{ key, label, value, kind?: "delta" \| "total" }[]` | — | delta（默认）在上一步的累计上加 value；total 的 value 本身是累计（期初、期末），柱从 0 起。 |
| `label` | `string` | — | 整张图的读屏名（必填）。 |
| `formatValue` | `(value: number, bar: WaterfallBar) => string` | — | 柱上与读数里的数怎么写：增减柱传这一步的值，总计柱传累计，纵轴刻度也走它（当作总计）。正负号与单位由调用方定。 |
| `formatGap` | `(gap: number) => string` | — | 总计柱对不上时读数里补的那句；不给就不提。 |
| `zeroBaseline` | `boolean` | `false` | 纵轴从 0 起、总计柱从 0 画。默认不从 0 起：纵轴取累计值的最低到最高再加 10% 余量（待定），总计柱是从轴底起的截断柱，期初是大数时增减才看得清。 |
| `height` | `number` | `200` | 图高（px）。 |

## States

- 默认：涨跌总计三种颜色，柱顶写数。
- 扫读：选中的柱保持原色，其余变淡，下面一行写这一步的名字与值。
- 总计柱对不上：画虚线框，读数写差额。
- 一步为 0：画一条细线，既不涨也不跌的中性色。

## Don't

- 不要拿它画不连续的几组数：每一步都接着上一步的累计，不相关的数用柱状图。
- 不要在包里写「未实现」「手续费」这类词：步骤名与差额的说法都由调用方传。
- 不要靠颜色单独传达涨跌：柱顶的数带正负号，读屏列表写满每一步。

## Composition

```
WaterfallChart
  div[role=group]（svg：网格 · 零线 · 连线 · 柱；柱顶数字 · 纵轴刻度）
  步骤名一行 · 读数行（aria-live）
  ul.sr-only（每一步一句）
```

## Keyboard

- `← →`：选中前后一根柱；没选中时先落到最后一根
- `Shift + ← →`：一次三根
- `Home / End`：第一根 / 最后一根
- `Esc`：清掉选中
