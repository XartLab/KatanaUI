# Kbd

把一个快捷键组合画成一串小方块：20 高、圆角 4、6% 白底 12% 白边。

## Provide

### Kbd

怎么把「Mod+Shift+H」拆成块、Mod 在这个平台叫什么，是调用方的事。

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `parts` | `readonly string[]` | — | 每一块上的字。 |
| `label` | `string` | — | 读屏读的整串（必填）。 |

## States

- 一个组合画成一串小方块；单键与多键。

## Don't

- 不要把快捷键写成普通文字加方括号。

## Composition

```
Kbd
```
