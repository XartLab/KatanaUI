# 联动组 useLinkGroup 与选组件 LinkGroupPicker

几张件按颜色分组（A–D），同组里任一张换品种，组里其余件跟着换；「不联动」的件只管自己。件的标题栏最左是选组件：一个带联动灯的小按钮，点开是 A–D 四组加「不联动」的单选菜单，当前那组打勾，每组行尾写这组现在的品种。选进有品种的组，件改看组的；选进空组，组取这件现在的品种，件不跳回去；选「不联动」，件回到自己起头的品种，之后谁换都不互相影响。页上另有 #22 的演示：自选点品种，同组的两张图一起换；在一张图上移动指针，另一张同时画十字线。

## Sub-features

- `link-sync` 同组同步：在一张件里换品种，同组的件跟着换，别组的不动。
- `link-menu` 选组菜单：点灯打开，A–D 与「不联动」五项，当前组打勾，每组行尾是这组现在的品种（空组不写）。
- `link-join` 进有品种的组：件改看组的品种，之后与组里的件同步。
- `link-join-empty` 进空组：组取这件现在的品种，件留着原来的品种；离开的那组再换品种它不跟。
- `link-unlink` 不联动：灯变空环，件回到自己起头的品种；组里换品种它不跟，它自己换也不动组。
- `link-keyboard` 键盘选组：焦点在灯上按 Enter 开菜单，↑ / ↓ 换项、End 到底，Enter 选中、Esc 不选；关上后焦点回到灯。
- `link-watch` 自选联动（#22）：自选点品种，同组的图 1、图 2 标题栏一起换。
- `link-crosshair` 十字线联动（#22）：指针在图 1 的灰条上，图 2 同时画十字线，两张图的读数一样。

## How to get to it (user POV)

- 文档站左侧目录「积木 → useLinkGroup 联动组」，地址 `#/link-group`。
- 页上第一段是 #22 的演示：一排自选（`BTCUSDT`、`ETHUSDT`、`NVDA`、`QQQ`），下面图 1、图 2 两张面板，都在 A 组，各带「周期」和「联动组」两排按钮。
- 第二段「选组件 · 三张小件 · 两组」：三张面板 `报价`、`迷你图`（组 A，起头 `AAA`）、`说明`（组 B，起头 `CCC`）。每张标题栏最左是选组件（读屏名 `联动组: 组 A` 这样），内容区顶上一排「换品种」按钮 `AAA`、`BBB`、`CCC`、`DDD`。这三张接自己的一张联动表，不和第一段串组。
- 第三段「选组件的五种样子」：A–D 四组与不联动的灯，只看样子。

## Driving it with kui.mjs

前置：`$KUI doctor` 全 OK；打开 `#/link-group`，等 `[data-gallery="link-group"]` 出来。面板用 `getByRole('region', { name: '报价', exact: true })` 收；一张件显示的品种读它「`报价：换品种`」那排里 `aria-pressed="true"` 的按钮，再对一下标题栏 `.k-panel-object` 的「· 品种」。选组件用 `[data-gallery-link-panel="报价"] [data-slot="link-group-picker"]` 收；菜单是 `getByRole('menu', { name: '联动组' })`，每项是 `menuitemradio`，行尾品种在 `[data-slot="link-group-symbol"]`。

- **默认。** 打开页。三个选组件的 `aria-label` 依次是 `联动组: 组 A`、`联动组: 组 A`、`联动组: 组 B`；三张件显示 `AAA`、`AAA`、`CCC`。
- **同组同步。** 在报价里点 `BBB`。报价、迷你图都是 `BBB`，说明还是 `CCC`。
- **选组菜单。** 点说明的选组件。按钮 `aria-expanded="true"`；菜单五项，ARIA 名依次是 `组 A BBB`、`组 B CCC`、`组 C`、`组 D`、`不联动`；`组 B` 的 `aria-checked="true"`。
- **进有品种的组。** 点 `组 A`。菜单关上，焦点回到说明的选组件，它的名字变成 `联动组: 组 A`；说明改看 `BBB`。再在说明里点 `DDD`，三张都是 `DDD`。
- **进空组。** 迷你图的选组件里点 `组 C`（行尾没有品种）。迷你图留着 `DDD`，名字是 `联动组: 组 C`。在报价里点 `AAA`：报价、说明是 `AAA`，迷你图还是 `DDD`。再开迷你图的菜单，`组 C` 行尾是 `DDD`、`组 A` 行尾是 `AAA`；按 Esc 关上。
- **不联动。** 说明的选组件里点 `不联动`。名字 `联动组: 不联动`，`data-group="none"`；说明回到 `CCC`。在报价里点 `BBB`，说明还是 `CCC`；在说明里点 `AAA`，报价还是 `BBB`。
- **键盘选组。** 焦点放到报价的选组件上按 `Enter`：菜单打开，焦点在 `组 A`；等菜单进场动效走完，按 `ArrowDown` 到 `组 B`，再按到 `组 C`，按 `Enter`。菜单关上，焦点回到报价的选组件，名字 `联动组: 组 C`，报价改看 `DDD`（迷你图也是 `DDD`）；在报价里点 `CCC`，迷你图跟着变 `CCC`。
- **键盘不选。** 焦点放到迷你图的选组件上按 `Enter`，按 `End` 焦点到 `不联动`，按 `Escape`。菜单关上，焦点回到按钮，名字还是 `联动组: 组 C`，品种不变。
- **自选联动。** 第一段 `getByRole('group', { name: '自选', exact: true })` 里点 `NVDA`。图 1、图 2（`region`）标题栏 `.k-panel-object` 都是 `NVDA`。
- **十字线联动。** 图 2 的读数 `[data-slot="crosshair-readout"]` 起头是 `十字线：—`。指针移到图 1 的 `[data-slot="crosshair-strip"]` 中间（`hover()`）：图 2 的读数变成和图 1 一样（2026-11-23 实测都是 `十字线：02:00`）。
- **证据。** `$KUI drive link-group`：十一步十一张截图，`link-group-menu.aria.yml` 是说明那次打开的菜单的 ARIA 快照。

## Gotchas

- 菜单开着时，Radix 给菜单以外的内容挂 `aria-hidden`，`getByRole('region', …)` 找不到面板：开着菜单时读选组件要用 `data-gallery-link-panel` 收，不要用角色。
- 选组件的读屏名随组变（`联动组: 组 A` → `联动组: 组 C`），别拿名字收按钮，换完组就找不到了。
- 菜单项的 ARIA 名带着行尾的品种（`组 A BBB`），按组名找项要用前缀（`name: /^组 A/`）；`不联动` 没有品种，可以 `exact`。
- 键盘开菜单后马上按两次 ↓，第一次可能落在进场动效里被吞掉（2026-11-23 走查时焦点停在 `组 B`）：先等菜单的动画走完，每按一次读一次焦点。
- 第一段（自选与图）用的是整页默认的联动表，第二段三张件各接自己的一张，两段的 A 组互不相干；第三段五个样子的选组件读的是默认表，菜单里会看到第一段 A 组的品种。
- 这条流程一路改了页上的状态（组和品种），步与步有先后：只想看一个子功能，从头跑，或刷新页再手走。
