# OrderBook 订单簿

买卖挂单的阶梯：卖盘在上、买盘在下，中间一行是最新价与价差；切模式可以只看一侧（那一侧行数翻倍），切档位把挂单按 tick 合并——买盘向下取整、卖盘向上取整；每行底下一条累计量深度条，底部一条买卖占比条。点一行把「这个价、这一侧」交给调用方，文档站回显在书下面。

## Sub-features

- `book-mode` 切「买卖 / 只看买 / 只看卖」：收起的那一侧不在页上，留下的那侧行数翻倍，中间行贴着它的最优价。
- `book-tick` 切合并档位：每一行的价都是档位的整数倍，买盘比真实挂单低、卖盘比真实挂单高，同档的量相加。
- `book-pick` 点一行：行是按钮，回调收到 `{ price, side }`，回显写「点价：… · 买盘/卖盘」。
- `book-share` 占比条：买占比 = 买量 ÷（买 + 卖）保留一位小数，卖占比 = 100 减买占比，两个数相加恰好 100；读屏从同一条 `aria-label` 读。
- `book-depth` 深度条：每行的累计量占显示行里最大累计量的比例，买盘走涨色、卖盘走跌色。

## How to get to it (user POV)

- 文档站左侧目录「积木 → OrderBook 订单簿」，地址 `#/order-book`。
- 书在「订单簿 BTC-演示」面板里；上面的「实时 / 暂停」是全局开关，演示数据来自 `gallery/book-sim.ts` 的模拟器（固定种子，不是行情）。
- 演示参数：价格两位小数、数量三位小数，档位 `0.01 / 0.05 / 0.1 / 0.5 / 1`，每侧 8 行。

## Driving it with kui.mjs

前置：`$KUI doctor` 全 OK。书是 `section.locator('[data-slot="order-book"]').first()`，模式与档位是两个 `role="group"`（`显示模式`、`合并档位`），项都是 `aria-pressed` 的钮；行是 `[role="list"][data-side="ask|bid"] [data-slot="book-row"]`，行价读 `data-price`。

- **默认。** 打开页。`data-mode="both"`；「数据刷新」组里「暂停」是 `aria-pressed="true"`（自动化浏览器默认暂停，`live-sim.ts` 看 `navigator.webdriver`）；买卖各 8 行；中间行价差 `0.01`；占比写「买盘占 48.7%，卖盘占 51.3%」。
- **只看卖。** 点「只看卖」。`data-mode="asks"`，买盘 0 行、卖盘 16 行，占比文案一字不变。
- **只看买。** 点「只看买」。`data-mode="bids"`，卖盘 0 行、买盘 16 行，占比仍不变。
- **切回买卖。** 点「买卖」。两侧各 8 行。
- **合并档位。** 点档位 `0.5`。每侧的 `data-price` 都是 0.5 的整数倍：卖盘 `104, 103.5, …, 100.5`，买盘 `100, 99.5, …, 96.5`。
- **点价。** 点卖盘第一行。回显写「点价：104.00 · 卖盘」；再点买盘第一行，回显写「点价：100.00 · 买盘」。
- **档位调回 0.01。** 卖盘回到 `100.08 … 100.01`，买盘 `100.00 … 99.93`，各 8 行。
- **占比。** 占比条的 `aria-label` 匹配 `买盘占 \d+\.\d%，卖盘占 \d+\.\d%`，两个 `data-pct` 相加正好是 `100`。
- **证据。** `$KUI drive orderbook`：九步九张截图，`orderbook-both.aria.yml` 是默认状态整本书的 ARIA 快照，`orderbook-tick-05.aria.yml` 是切到 0.5 以后的。

## Gotchas

- 演示数据是模拟器（`gallery/book-sim.ts`，种子 7），量每拍会变；自动化浏览器里默认暂停，暂停下不能断言「量变闪色」。要验闪色：开「实时」或用 `window.__liveStep(n)` 手动走一拍，再看 `[data-slot="book-size"][data-flash]`。
- 行价从 `data-price` 读，不要从 `.k-book-price` 的文字里 `parseFloat`：文字按 `priceDecimals` 补两位小数，档位比价格细时看不出真实值。
- 占比只数每侧前 `depth` 行（演示是 8）：切模式行数翻倍、占比不动是设计，不是 bug。
- 「买盘向下、卖盘向上」在文档站上只看得到结果（行价都是档位整数倍）；边界（档位比价格最小位还细、非法档位按价格最小位）由 `.claude/skills/formal-tick-merge/` 的性质测试管。
- 没有「空簿」入口：演示数据始终有档位，`labels.empty`（没有档位）在文档站上走不到。
- 档位的钮按十进制字面量命名（`0.01`、`0.05`、`0.1`、`0.5`、`1`）：用 `exact: true`，`1` 才不会撞上 `0.1`。
